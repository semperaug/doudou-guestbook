🧭 主题分组（6 大主线）

主线 ① AI 的账本第一次被公开核对：8954 亿美元承诺 vs 2 万亿 Token 货架

核心论点：本窗口最重要的一次认知位移，是把"AI 很贵"从形容词变成了三种可以分别核对的账单——巨头的账（Anthropic 8954 亿美元算力承诺 / 苹果内存成本警告 / 谷歌与 Meta 自由现金流齐转负）、用户的账（OpenAI 12 月起 ChatGPT 与 Codex 合并额度并改按 Token 计量）、以及被两边忽略的中间层——国产链的账（千亿融资不推高估值 + 千问 Token 上直播货架）。上一窗口说"廉价资金枯竭"，本窗口把这句话拆成了三张单据，每一张都有独立的、可被验证的载体。

证据一：巨头的账——Anthropic 的 8954 亿美元，比 6000 亿口径更完整。 11-03 cron 输出存档补录了 S-1 的更新口径：前三季度营收 332.4 亿美元、同比增约 1200%，第三季度单季近 170 亿；净亏损 1040 亿美元，累计算力采购与租赁承诺约 8954 亿美元。这与 11-02 素材的"未来算力承诺超 6000 亿美元、近八成照付不议"、11-01 素材的 S-1 原文"已承诺 5180 亿美元基础设施支出"形成三个逐日递进的口径——5180 亿（半年基础设施）→ 6000 亿（含照付不议）→ 8954 亿（前三季度累计全部算力采购与租赁承诺），三个数字不冲突，是覆盖范围依次扩大。11-03 素材进一步给出时间分布：截至 9 月底各项承诺支出总额达 8950 亿美元，其中约 4480 亿美元预计 2030 年底前发生——算力长约已成行业通病。同日 11-02 素材的另一记重锤：黑石告知投资者 Anthropic 上市后信评可能落在 BB 级"垃圾级"区间，与此前指引相悖。

证据二：用户的账——12 月起，ChatGPT 的免费重置时代结束。 11-03 素材：12 月起 Plus、Pro、Business 三档付费套餐的 ChatGPT 与 Codex 用量合并为同一个额度池，统一按 Token 而非消息数计量，只有 Instant 快速聊天例外不扣额度；OpenAI 产品负责人此前自称"从重置额度的公司毕业，成为 Token 公司"；同时推出设备端付费账号数量限制，堵死多账号轮换的漏洞；具体各档 Token 配额和上线日期均未公布。这是本窗口最被低估的一条——它意味着 ChatGPT 的定价单位正在从"消息"切换到"算力"，与 10-28 素材里 GPT-6.1 Terra"输入 1 美元／输出 5 美元每百万 token"的降价形成完整闭环：API 端价格腰斩，C 端反而开始按 Token 计量收费，中间被"免费额度"掩盖的那部分成本正在浮出水面。

证据三：Token 第一次变成货架商品。 11-03 素材：11 月 2 日晚李佳琦直播间开卖千问办公 Token，半小时售出 10 万份千问办公个人会员月卡，累计约 2 万亿 Token，千问办公 CEO 陈宇森做客直播间演示办公与生活场景；这个数字同时冲上百度热搜。素材点评一针见血："Token 被李佳琦卖成了快消品"。这条与证据二互为镜像：当 C 端开始按 Token 计量收费，Token 就必须找到一种能被普通人理解的价格锚——而直播带货正是中国最成熟的"解释复杂商品"的方法论。同一周里，OpenAI 宣布按 Token 计量，李佳琦把 Token 卖成了月饼——AI 的计价单位第一次完成了从工程语言到大众商品语言的翻译。

证据四：供应链的账开始传导到终端。 11-03 素材：苹果 FY2026 Q4 营收 1145 亿美元同比增 12%、iPhone 收入 575.8 亿增 17%、大中华区 175.4 亿增 21%、EPS 2.10 美元超预期，但 CFO 电话会称内存采购成本将持续上涨、研发投入使运营费用攀升 21%、两个季度间制造采购义务增加 330 亿美元，预计 Q1 营收增速降至 7%–10%，盘后股价一度跌 4%。这与 11-02 素材"存储占手机 BOM 成本从约 10% 飙至 34%、2027 上半年或破 40%、iPhone 18 Pro 涨 5000 元起"是同一条链的两端：巨头报表上的内存采购义务增加 330 亿美元 ↔ 消费者手里的手机涨 5000 元。

证据五：把这条链补完——国产链的账是反着记的。 11-03 素材：Marvell Technology 与光通信设备商 Lumentum 达成最终协议，隐含企业价值约 1150 亿美元，较 10 月 28 日传闻前收盘价溢价约 23.9%，Lumentum 股东每股换 4.5 股 Marvell 普通股，交易后原股东持股约 33%；合并后瞄准覆盖电互连、光互连、光收发器等业务的 5500 亿美元市场，预计年成本协同超 10 亿美元，2028 年上半年完成。这条是本窗口的新证据：海外侧的钱仍在往"AI 连接"这个确定性环节砸，Marvell 用千亿并购告诉市场"光互连的产能已经被锁定五年"；而国产侧的钱则往"国产模型 + 国产终端入口"走（见主线 ②）。同一个 AI 周期，两边的资金流向完全不同。

主线 ② 国产链的定价权位移：从"融到多少钱"到"谁在定价、谁在分发"

主线 ④ Agent 与具身智能：从架构开源到"Token 上货架"

核心论点：本窗口把 Agent 这条线推过了三个门槛——架构（DeepSeek Super-agent 开源且被 GitHub 社区追到 star 增长榜第一）、产品（AI 办公三国杀的工程竞赛进入成本可比阶段）、以及变现（Token 第一次成为可被普通人按份购买的商品）。而具身智能这条线的进展则是国产侧量产 + 海外侧绑定模型，两条路径开始分岔。

证据一：DeepSeek Super-agent 成为本窗口最热的开源项目。 11-01 素材：10 月 31 日晚 DeepSeek Harness 团队在官方公众号发表《Super-agent 设计探索：迈向更自主的Agent系统》，并同步在 GitHub 开源原型 deepseek-ai/dsh-superagent-prototype（MIT 许可、TypeScript、216 个文件，5 小时内 754 星、50 fork）。核心命题：模型执行单任务越来越不需要人干预后，瓶颈已从模型能力转向"人的注意力"——一个人通常只能同时跟进 3 到 5 个活跃 Session。解法是双层 Router-Worker 架构（Router 承接人类交互与全局上下文、Worker 在隔离会话并发执行，只向 Router 汇报）、事件驱动（群聊消息／CI 结果等 Trigger 先经程序规则过滤再交模型判断）、异步 ReAct Loop（耗时工具调用改为 start()/stop()）、存算分离（云端计算与状态 + 本地轻量 daemon，支持 BYOM）、以及独立 Watchdog 外部控制回路。四个特征：连续、高效、主动、持久。实验数据：任务完成 p50 12.4 分钟、p95 15.7 分钟（单 Session+Subagent 方案 p95 为 29.5 分钟）；Router 批处理把单个决定分摊的推理时间从 6.4 秒压到 1.6 秒；代价是读缓存 token 从 2323 万涨到 3177 万。团队明确说明这是架构思路探讨而非产品发布。

11-03 GitHub 热榜补录的社区数据（本周报新增维度）： dsh-superagent 是今日 star 增长榜第一名（24 小时内 +6,097，两天 13.2k stars）；11-03 每日新闻推送亦同步记录"同步开源编程智能体 dsh-superagent（MIT 协议）"。但 11-03 热榜评估同时给出关键安全提示：worker 以 danger-full-access 权限运行，能读操作者的 home 目录，作者要求你必须用专用 OS 账号隔离——且 11-01 素材已披露"DeepSeek Super-agent 官方自陈未经安全审计、沙箱不保证隔离"。"开源第一热度"与"未经安全审计"同时成立，这是本窗口 Agent 线上最具张力的一组事实。
